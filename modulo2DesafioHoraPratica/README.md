# Hora Prática - Operações Básicas

Este projeto contém diversos exercícios práticos envolvendo operações matemáticas, casting e concatenação em Java.

## Descrição

O programa demonstra conceitos fundamentais de Java através de vários exemplos práticos:
- Cálculo de média
- Casting de tipos
- Concatenação de strings
- Cálculos de valor total
- Conversão de moedas
- Cálculo de descontos

## Funcionalidades

1. **Cálculo de Média**: Calcula a média entre duas notas
2. **Casting**: Demonstra conversão de double para int
3. **Concatenação**: Concatena caracteres e strings
4. **Valor Total**: Calcula o valor total de produtos
5. **Conversão de Moeda**: Converte dólar para real
6. **Desconto**: Calcula valor com desconto percentual

## Como Executar

```bash
javac src/Main.java
java src/Main
```

## Conceitos Aprendidos

- Operadores aritméticos (+, -, *, /)
- Casting explícito de tipos
- Concatenação de strings com o operador +
- Formatação de saída com `System.out.println()`
- Cálculos de porcentagem
