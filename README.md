# Alura Java - Criando a Sua Primeira Aplicação

Este repositório contém uma coleção de projetos Java desenvolvidos durante o curso "Criando a Sua Primeira Aplicação" da Alura. Os projetos demonstram conceitos fundamentais da linguagem Java, desde operações básicas até estruturas de controle e interação com o usuário.

## 📁 Estrutura do Repositório

O repositório está organizado em módulos, cada um contendo projetos práticos que abordam diferentes conceitos de programação em Java:

- **modulo2DesafioConversao** - Conversão de temperatura (Celsius para Fahrenheit)
- **modulo2DesafioHoraPratica** - Exercícios de operações básicas, casting e concatenação
- **modulo3HoraPratica** - Condicionais, switch case e loops
- **modulo3JogoDeAdivinhacao** - Jogo interativo de adivinhação
- **oDesafio** - Simulador de conta bancária
- **primeiroPrograma** - Três programas básicos (condicionais, leitura e loops)

## 🚀 Como Executar os Projetos

Cada projeto pode ser compilado e executado individualmente:

```bash
# Navegue até o diretório do projeto desejado
cd nome-do-projeto

# Compile o código
javac src/Main.java

# Execute o programa
java src/Main
```

Para o projeto `primeiroPrograma`, existem três arquivos principais que podem ser executados separadamente:

```bash
javac src/Condicional.java && java src/Condicional
javac src/Leitura.java && java src/Leitura
javac src/Loop.java && java src/Loop
```

### Módulo 3

## 📖 Descrição dos Projetos

### modulo2DesafioConversao
Realiza a conversão de temperatura de graus Celsius para graus Fahrenheit, demonstrando operações matemáticas e casting.

### modulo2DesafioHoraPratica
Contém diversos exercícios práticos incluindo cálculo de média, casting, concatenação, conversão de moedas e cálculo de descontos.

### modulo3HoraPratica
Exercícios interativos que demonstram o uso de condicionais, switch case e loops através de verificações numéricas, cálculos de área e tabuada.

### modulo3JogoDeAdivinhacao
Jogo interativo onde o usuário deve adivinhar um número aleatório entre 0 e 100 em até 5 tentativas, com dicas a cada tentativa.

### oDesafio
Simulador de conta bancária com menu interativo para consultar saldo, receber valores, transferir valores e sair do sistema.

### primeiroPrograma
Três programas básicos que demonstram conceitos fundamentais: condicionais (verificação de filmes), leitura de dados (Scanner) e loops (cálculo de médias).
