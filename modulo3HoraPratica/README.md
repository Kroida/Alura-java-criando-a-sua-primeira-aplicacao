# Hora Prática - Condicionais e Loops

Este projeto contém exercícios práticos envolvendo estruturas condicionais, switch case e loops em Java.

## Descrição

O programa demonstra o uso de estruturas de controle de fluxo através de vários exercícios interativos:
- Verificação de número positivo ou negativo
- Comparação entre dois números
- Cálculo de área (quadrado e círculo) usando switch
- Verificação de par ou ímpar
- Tabuada de multiplicação

## Funcionalidades

1. **Número Positivo/Negativo**: Verifica se um número é positivo ou negativo
2. **Comparação de Números**: Compara dois números e informa se são iguais, maior ou menor
3. **Cálculo de Área**: Menu interativo para calcular área de quadrado ou círculo
4. **Par ou Ímpar**: Verifica se um número é par ou ímpar
5. **Tabuada**: Gera a tabuada de multiplicação de um número (de 10 a 1)

## Como Executar

```bash
javac src/Main.java
java src/Main
```
