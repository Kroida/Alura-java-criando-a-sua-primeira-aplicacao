# Conversão de Temperatura

Este projeto realiza a conversão de temperatura de graus Celsius para graus Fahrenheit.

## Descrição

O programa converte um valor em graus Celsius para graus Fahrenheit utilizando a fórmula:
```
Fahrenheit = (Celsius × 1.8) + 32
```

Além disso, demonstra o uso de casting para converter o resultado em número inteiro.

## Funcionalidades

- Conversão de temperatura de Celsius para Fahrenheit
- Formatação de string para exibição do resultado
- Casting de double para int para obter valor inteiro

## Como Executar

```bash
javac src/Main.java
java src/Main
```

## Exemplo de Saída

```
35.600000 graus Celsius equivalem a 96.080000 graus Fahrenheit
96.08 graus Fahrenheit em números inteiros ficam: 96
```

## Conceitos Aprendidos

- Operações matemáticas básicas
- Formatação de strings com `String.format()`
- Casting de tipos primitivos (double para int)
