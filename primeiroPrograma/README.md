# Primeiro Programa

Este projeto contém três programas básicos que demonstram conceitos fundamentais de Java: condicionais, leitura de dados e loops.

## Descrição

O projeto é composto por três programas independentes que ensinem conceitos essenciais da linguagem Java:
- `Condicional.java`: Demonstra o uso de estruturas condicionais if/else
- `Leitura.java`: Demonstra a leitura de dados do usuário via Scanner
- `Loop.java`: Demonstra o uso de loops para calcular médias

## Programas

### Condicional.java

Demonstra o uso de condicionais para verificar:
- Se um filme é lançamento ou retrô baseado no ano
- Se o usuário tem acesso ao filme baseado no plano e inclusão

### Leitura.java

Demonstra a leitura de diferentes tipos de dados do usuário:
- String (nome do filme)
- Inteiro (ano de lançamento)
- Double (avaliação)

### Loop.java

Demonstra o uso de loops para:
- Ler múltiplas avaliações
- Calcular a média das avaliações

## Como Executar

```bash
javac src/Condicional.java
java src/Condicional

javac src/Leitura.java
java src/Leitura

javac src/Loop.java
java src/Loop
```

## Conceitos Aprendidos

- Estruturas condicionais (if/else)
- Operadores lógicos (&&, ||)
- Leitura de dados com Scanner
- Loops (for)
- Cálculos de média
- Tipos primitivos e objetos
- Comparação de strings com equals()
